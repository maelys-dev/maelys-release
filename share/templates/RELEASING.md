# Releasing @PRODUCT@

Releases go through the shared maelys-release socle (@SOCLE_TAG@). The
workflow `.github/workflows/release.yml` and `scripts/checkout-dependency.sh`
are generated by its `maelys-release adopt` from `VERSION`, `adapter/*_PIN`,
`adapter/PACKAGES` and `packaging/homebrew/*.rb.in`.

1. On `main`: `VERSION` = `X.Y.Z`, dated `CHANGELOG.md` entry, generated
   documentation regenerated, `make check` green on the exact commit.
2. Merge through a pull request with green CI (`ci.yml` runs the socle's
   `check-product.yml` on the three release targets). Before a first
   release or after a packaging change, `maelys-release rehearse . linux-arm64`
   replays the Linux build job in Docker.
3. `maelys-release preflight .` from a maelys-release checkout at @SOCLE_TAG@:
   signing configuration, previous tag, free `vX.Y.Z`, `release` environment.
4. `git tag -s vX.Y.Z -m "@PRODUCT@ X.Y.Z" && git push origin vX.Y.Z`.
5. The workflow verifies the signed annotated tag, clones the pinned
   dependencies, installs the declared packages, builds the packages on
   Linux x86_64, Linux arm64 and macOS arm64, attests their provenance
   (public repository only: a private one ships the signed tag and
   `SHA256SUMS`), publishes the GitHub release, then renders and publishes
   the Homebrew formula with its bottles.
6. Verify: `gh release view vX.Y.Z`, `gh attestation verify ASSET --repo
   OWNER/REPO --signer-repo maelys-dev/maelys-release` (the attestation is
   signed by the socle's reusable workflow), `brew install
   maelys-dev/tap/@PRODUCT@`.

Upgrade the socle with `maelys-release adopt DIR --apply` from a maelys-release
checkout at the wanted tag; `maelys-release check DIR` reports drift with exit 2.

## Replaying the Homebrew publication of a tag

When the release was published but the tap jobs failed, adopt the corrected
socle on the default branch, then run the `release` workflow by hand with the
existing tag as input: `gh workflow run release.yml -f tag=vX.Y.Z`. The
release job is skipped; the tap jobs render, bottle and publish again.
